Nome Variabile nel Codice	Categoria	Significato Fisico Dedotto
Struttura 

PilotInput
stick_roll	Input di Controllo	Input del pilota sull'asse di rollio (cloche sx/dx) [-1.0, 1.0]. In Normal Law comanda il rateo di rollio desiderato.
stick_pitch	Input di Controllo	Input del pilota sull'asse di beccheggio (cloche su/giù) [-1.0, 1.0]. In Normal Law comanda il rateo di beccheggio.
rudder	Input di Controllo	Input della pedaliera per l'imbardata [-1.0, 1.0].
speed_delta	Input di Controllo	Input per variare la velocità (manetta) [KPH/frame]. Nel codice attuale non comanda una vera spinta, ma un incremento/decremento diretto della velocità.
Struttura 

FlightState
x, z	Stato Cinematico	Posizione planimetrica rispetto al suolo (Est/Ovest, Nord/Sud) misurata in metri.
altitude	Stato Cinematico	Quota rispetto al suolo misurata in metri.
speed	Stato Cinematico	Modulo del vettore velocità (TAS - True Airspeed) misurata in KPH. Non sono presenti le componenti vettoriali (u, v, w).
roll, pitch, yaw	Stato Cinematico	Atteggiamento spaziale dell'aereo (Angoli di Eulero in radianti).
roll_rate, pitch_rate, yaw_rate	Stato Cinematico	Velocità angolari del body-frame (p, q, r) misurate in rad/s.
Struttura 

ControlSurfaces
aileron_deflection	Output FCC / Input Fisico	Deflessione calcolata degli alettoni (gradi).
elevator_deflection	Output FCC / Input Fisico	Deflessione calcolata dell'equilibratore (gradi).
rudder_deflection	Output FCC / Input Fisico	Deflessione calcolata del timone (gradi).
thrust_normalized	Output FCC / Input Fisico	Comando motore normalizzato [0.0, 1.0]. Attualmente definita ma non usata (la fisica usa speed_delta applicato direttamente a speed).
Parametri Hardcoded (

FlightControlComputer.cpp
)		
EFF_AIL (0.06)	Parametro Aerodinamico	Efficacia degli alettoni (coefficiente moltiplicativo diretto tra deflessione e rateo di rollio).
EFF_ELEV (0.04)	Parametro Aerodinamico	Efficacia dell'equilibratore (coefficiente moltiplicativo diretto tra deflessione e rateo di beccheggio).
- Massa, Gravità, Inerzia	Parametro Fisico/Massa	ASSENTI. Completamente omesse. Tutta la cinematica è risolta integrando geometricamente angoli e velocità senza il concetto di forza/massa.
- Densità dell'aria, Vento	Parametro Ambientale	ASSENTI. Nessun modello atmosferico.
- Portanza, Resistenza	Forza/Momento	ASSENTI. La fisica simula la caduta usando euristiche scriptate (es: sink rate applicato se speed < 60 o modulo del roll > 1.4). Nessun calcolo aerodinamico reale.
